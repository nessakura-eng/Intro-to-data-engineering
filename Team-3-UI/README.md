# Grace Place Onboarding Passport (Team 3 UI)
React + Vite demo of the 10-table schema, loaded with the Team-3-Data.sql rows (src/data.json).
    npm install
    npm run dev
Sample logins (password for all: Passport2026!): manager dana.whitfield; new hire avery.nguyen. Others are listed on the login screen.
New hires can only press Get Started (Not started -> In progress). Managers mark tasks Completed.
Changes are saved in this browser's localStorage. "Reset sample data" on the login screen restores the original rows.
Branding: src/logo.jpg is the Grace Place logo supplied by the client; colors are sampled from it.
